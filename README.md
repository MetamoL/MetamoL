## めたもる / MetamoL

生成AI（Claude Code / Codex）を開発の中心に置いて、アプリと Web サービスを作って運用しています。
実装は AI に任せ、要件・設計判断・レビュー・テスト方針・リリース判断を自分が担う、というやり方です。

### 作っているもの（公開中）
- **ヨミツギ** — Web 小説リーダーアプリ（iOS / Android）
  [App Store](https://apps.apple.com/jp/app/id6778637183) ・ [Google Play](https://play.google.com/store/apps/details?id=com.metamol.yomitsugi)
  Flutter / AWS Lambda（Python）/ Firebase / RevenueCat
- **FrameSpec** — 遊びたいゲームと目標の fps から、根拠つきでゲーミング PC を選べるサービス
  [framespec.net](https://framespec.net)
  AWS Lambda（Node.js）/ DynamoDB / S3 + CloudFront / Anthropic API
